# 图片改为「保存时」才复制进托管目录

> 部分被 ADR-0006 取代：自 v0.1.3 起，**已落库示例**选图 / 拖图即入库；本决策仍适用于草稿。

原实现在选图 / 拖图当下就调用 `store_image_bytes` 写进 `data/images/`，但最初需求与此前写好的 UI 文案（「草稿落库：此时才把图片复制入库」「已选择图片 W×H（保存后入库）」）都声称是保存时才入库。改为只记住源文件路径、保存时才读取并按内容哈希写入：这样放弃草稿或连续试选多张图，都不会在托管目录留下永不清理的孤儿文件，也让既有文案变回真话。代价是源文件若在保存前被移动或删除，保存会失败并提示重新选择。
