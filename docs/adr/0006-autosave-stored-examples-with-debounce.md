# 已落库示例的内容改动自动写库，草稿仍需手动落库

ADR-0004 定下「选图只记源路径、保存时才复制入库」，前提是存在一个明确的「保存时刻」。但已落库示例的重命名本来就是即改即存，内容改动却要手动点「保存」，导致用户在示例间切换时被「是否保存」确认框拦住。改为：已落库示例的五分区文本在停止输入 500ms 后自动写库，图片选入 / 拖入 / 移除也立即写库（这一条部分取代 ADR-0004）；切换示例、失焦、关窗、导出、上锁前强制 flush，确保任何离开当前示例的动作都不再有未落库改动。草稿保持原语义——只有点「保存为新示例」才落库，因此仍可用 Pending Image 放弃试选。代价：写库次数增加（防抖后每次输入停顿一次写）；已落库示例放弃一次更换会留下孤儿图片文件（托管目录内容寻址天然去重，且删除示例本就不删图，接受）；写库失败（磁盘满 / 文件被占用）时保留内存内容并在状态栏红字报错，切换前 flush 失败则取消本次切换。
